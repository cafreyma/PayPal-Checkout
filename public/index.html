PayPal Standard Checkout

Same $10 USD sandbox order, rendered with each JS SDK version.

01JS SDK v5 — Buttons only (PayPal + Card)

components=buttons → paypal.Buttons() with no fundingSource renders the full smart button set

02JS SDK v6 — Web Components

https://www.paypal.com/web-sdk/v6/core → createInstance() → findEligibleMethods()

03JS SDK v6 — PayPal Button + Card Fields

components: ["paypal-payments", "card-fields"] → createCardFieldsOneTimePaymentSession()

04JS SDK v6 — Radio: PayPal or Card (custom icons)

components: ["paypal-payments", "card-fields"] → radio toggles which session's UI is shown; no v6 marks component exists, so icons are custom SVGs

05JS SDK v6 — Basic Apple Pay

components: ["applepay-payments"] → createBasicApplePayOneTimePaymentSession()

06JS SDK v5 Radio (PayPal + Card) + Basic Apple Pay (v6), with real Marks

data-namespace="paypalV5"/"paypalV6" → paypal.Marks() for PayPal/Card, <apple-pay-mark> for Apple Pay, next to each radio

07JS SDK v6 Radio (PayPal + Card) + Basic Apple Pay

components: ["paypal-payments", "card-fields", "applepay-payments"] → radio toggles which session's UI is shown; real <apple-pay-mark>, custom icons for PayPal/Card

08JS SDK v5 Buttons (PayPal + Card) + Basic Apple Pay (v6)

No radio — marks row (PayPal/Card via v5 paypal.Marks(), Apple Pay via <apple-pay-mark>) above all three buttons, shown upfront

09JS SDK v6 Web Components + Basic Apple Pay

components: ["paypal-payments", "paypal-guest-payments", "applepay-payments"] → marks row (custom icons + <apple-pay-mark>) above the three buttons

10JS SDK v6 PayPal Button + Card Fields + Basic Apple Pay

components: ["paypal-payments", "card-fields", "applepay-payments"] → marks row (custom icons + <apple-pay-mark>) above the three buttons
